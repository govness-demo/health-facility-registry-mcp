# Health facility registry MCP server

MCP server over the national health facility registry: search facilities, services and opening hours.

## Overview

Gives assistants an authoritative list of health facilities, so referrals point to places that exist and are open.

## Tools

- `search_facilities`
- `facility_services`
- `nearest_facility`

## Interfaces

Protocol: `mcp`. Languages: en.
